
# 🖼️ Smart Image Processing & Enhancement Toolkit

A Python-based image processing application built using Streamlit and OpenCV. It provides various tools to enhance, edit, and transform images through a simple and interactive web interface.

## ✨ Features

- **Grayscale Conversion** – Convert color images into grayscale.
- **Brightness & Contrast Adjustment** – Improve image brightness and contrast.
- **Image Denoising** – Reduce unwanted noise from images.
- **Image Sharpening** – Enhance image details and edges.
- **Edge Detection** – Detect image edges using the Canny algorithm.
- **Background Removal** – Remove image backgrounds.
- **Text-to-Image Generation** – Generate images from text prompts using Stable Diffusion.

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenCV
- NumPy
- Pillow
- TensorFlow
- Hugging Face Diffusers
- Stable Diffusion

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/komalmasute11-max/Smart-Image-Processing-Toolkit.git
```

### 2. Navigate to the project folder

```bash
cd Smart-Image-Processing-Toolkit
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.
